# 레인보우 스카이 러너

브라우저에서 index.html을 열어 플레이하는 달리기·점프 게임입니다.

- 방향키 또는 A/D: 이동
- Space / 위 방향키 / W: 점프
- Shift: 빠르게 달리기
- Enter: 시작 / 다음 레벨 / 재도전
- P: 일시 정지, M: 소리, R: 레벨 다시 시작

네 구역의 긴 코스를 지나 마지막 슈퍼별을 먹으면 레벨업합니다. 괴물에 닿으면 탈락하며 다음 레벨에서는 괴물이 빨라집니다. 일반 별 40개 수집, 체크포인트, 배경음악과 효과음, 최고 기록 저장을 지원합니다.

게임 시작 버튼을 누르면 소리가 활성화됩니다. 최고 기록은 브라우저에 저장됩니다.
